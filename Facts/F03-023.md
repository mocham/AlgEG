# Statement


Let $K\subset U$ be a $\bT$-stable normal subgroup with root set $\Phi_K$, descending-central-series height $\Ht_K$, and $K$-simple roots $\Delta_K=\{\alpha\in\Phi_K:\Ht_K(\alpha)=1\}$. Give $\Phi_K$ the directed-graph structure with an edge $\beta\to\alpha$ when $\alpha-\beta\in\Delta_K$. For each integer $h$, define $\fB(\Phi_K,\Delta_K,h)$ to be the induced subgraph on roots of $K$-height $h$ or $h+1$. Since $K$-height need not be additive and the full graph can have edges that skip layers, the layered directed structure relevant here equivalently retains an edge $\beta\to\alpha$ exactly when $\Ht_K(\alpha)-\Ht_K(\beta)=1$ and $\alpha-\beta\in\Delta_K$; only these bipartite graphs are used.
