# Statement


Let $A$ be a nonzero commutative ring with an action of a group $\Gamma$, let $M$ be an $A$-module with compatible semilinear $\Gamma$-action, and let $X$ be an $M$-torsor with compatible $\Gamma$-action. Assume the underlying $M$-torsor has an ordinary section $x_0\in X(A)$. Define
\[
c_\gamma=\gamma(x_0)-x_0\in M.
\]
Then $c=(c_\gamma)$ is a $1$-cocycle, and its class $[c]\in H^1(\Gamma,M)$ is independent of $x_0$. The torsor $X$ has a $\Gamma$-fixed section if and only if $[c]=0$. More generally, for every faithfully flat $\Gamma$-equivariant $A$-algebra $B$, the base change $X_B$ has a $\Gamma$-fixed section if and only if the image of $[c]$ in $H^1(\Gamma,M\otimes_A B)$ is zero. Thus an invariant generator of the linear module $M$ does not by itself imply the existence of a fixed point of the affine torsor.

# Proof or Examples


## Expanded self-contained proof

Compatibility of the affine action gives
\[
c_{\gamma\eta}=\gamma\eta(x_0)-x_0=c_\gamma+\gamma(c_\eta),
\]
so $c$ is a $1$-cocycle. Replacing $x_0$ by $x_0+m$ changes it to
\[
c'_\gamma=c_\gamma+\gamma(m)-m,
\]
which differs by a coboundary. Hence $[c]$ is intrinsic. The section $x_0+m$ is fixed by every $\gamma$ exactly when $c_\gamma+\gamma(m)-m=0$ for every $\gamma$, which is exactly the condition $[c]=0$. The same calculation after any equivariant base change $A\to B$ proves the base-change assertion.

For a concrete distinction, take $A=\mathbb F_p$, $\Gamma=C_p=\langle\gamma\rangle$, and $M=A$ with trivial action. Let $X=\mathbb A^1_A$ with $\gamma(x)=x+1$. This defines a $C_p$-action because $p=0$ in $A$. The linear module has invariant generator $1$, but the affine cocycle has $c_\gamma=1$ and no coboundaries are nonzero. After every faithfully flat nonzero $A$-algebra $B$, a fixed point would satisfy $x+1=x$, which is impossible. Thus the obstruction remains nonzero fppf locally.
