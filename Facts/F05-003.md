# Statement


Let $\mathbf G$ be a connected reductive group with connected center, let $\mathbf T\subset\mathbf G$ be a maximal torus, and let $\Delta$ be a set of simple roots. Then there exists a cocharacter $\lambda\in X_*(\mathbf T)$ such that $\langle\lambda,\delta\rangle=-1$ for every $\delta\in\Delta$.

# Proof or Examples


## Expanded self-contained proof

### Proof

Let Q be the root lattice Z Delta inside X^*(T). Connectedness of the center is equivalent, in the root datum, to X^*(T)/Q being torsion-free. Since this quotient is a finitely generated free abelian group, dualizing

0 -> Q -> X^*(T) -> X^*(T)/Q -> 0

gives a surjection X_*(T)=Hom(X^*(T),Z) -> Hom(Q,Z). Define f in Hom(Q,Z) by f(delta)=-1 for every simple root delta; this is well-defined because Delta is a basis of Q. Choose lambda in X_*(T) lifting f. Then <lambda,delta>=-1 for every delta in Delta, as required. Equivalently, lambda is the negative sum of the integral fundamental coweights.
