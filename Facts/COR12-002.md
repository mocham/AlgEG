# Statement


Let $n\ge4$ and realize $D_n$ with positive roots $M_{ij}=e_i-e_j$ and $P_{ij}=e_i+e_j$ in Bourbaki order. Fix a height $h$ and an arbitrary subset $T$ of the height-$(h+1)$ positive roots. Retain every height-$h$ root and only the targets in $T$, then repeatedly source-leaf contract and discard isolated sources.

For $h=2m$ with $1\le m\le\lfloor(n-2)/2\rfloor$, put $a=n-2m$ and define $K_{n,m}$ to have sources
\[
A_r=P_{a+r,n-r}\ (0\le r<m),\qquad B=M_{a,n},\qquad C=M_{a-1,n-1},
\]
targets
\[
Q_r=P_{a-1+r,n-r}\ (0\le r\le m),\qquad R=M_{a-1,n},
\]
and edges $A_r\to Q_r,Q_{r+1}$, $B\to R,Q_1$, and $C\to R,Q_0$. The terminal core is nonempty if and only if $h$ has this form and $T$ contains every target $Q_0,\ldots,Q_m,R$. In that case the terminal core is exactly $K_{n,m}$; otherwise it is empty.

For the target-by-source Jacobian of $K_{n,m}$ over the simple-root torus,
\[
\det J_{K_{n,m}}=\epsilon\,2x_{\alpha_{n-2m-1}}\prod_{i=n-m}^{n}x_{\alpha_i},\qquad \epsilon\in\{1,-1\}.
\]
Consequently every full-source target-induced Type D graph is admissible over any field of characteristic different from $2$. In particular it is admissible whenever $p>h_{D_n}=2n-2$, uniformly for every $n\ge4$.

# Proof or Examples


## Expanded self-contained proof

First perform the contractions in the minus-root chain used in COR12-001. This leaves the full core $K_{n,m}$ at an even height and leaves a source-ended path at every other height. Targets outside $K_{n,m}$ occur only in the part eliminated by that chain, so their selection does not affect the terminal graph. At an even height, if all $Q_0,\ldots,Q_m,R$ are selected, no source of $K_{n,m}$ has degree one and the core survives. If one of these targets is omitted, the connected unicyclic graph $K_{n,m}$ loses its unique cycle. Starting at a source adjacent to the missing target, source-leaf contractions peel the resulting alternating tree completely. Thus the terminal core criterion is exactly the one in the Statement. Odd and boundary heights already have a source endpoint and contract completely.

Order the rows so that the tail endpoint $Q_m$ comes first. Its only incident source in the core is $A_{m-1}$, so Laplace expansion forces that edge. Repeating along $Q_{m-1},\ldots,Q_2$ contributes
\[
\prod_{i=n-m}^{n-2}x_{\alpha_i}
\]
up to sign and reduces the determinant to the six-cycle on $A_0,B,C,Q_0,Q_1,R$. The two perfect matchings of this cycle have the same variable monomial
\[
x_{\alpha_{n-2m-1}}x_{\alpha_{n-1}}x_{\alpha_n}.
\]
The six relevant roots lie in the standard $D_4$ subsystem on $e_{n-2m-1},e_{n-2m},e_{n-1},e_n$. In a standard Chevalley basis all six constants have absolute value one and the two signed products agree, so their sum is $\epsilon2$. This is also the Type D six-cycle coefficient recorded in the source appendix. Multiplying by the forced tail entries gives the displayed determinant.

Every $x_{\alpha_i}$ is a unit on the base torus. Hence the core Jacobian is invertible when $2$ is invertible. A source-leaf contraction removes one equation together with a variable whose coefficient is a unit $N_{\beta,\delta}x_\delta$; in simply laced Type D, $N_{\beta,\delta}=\pm1$. Reversing the contractions therefore preserves smoothness and adds the expected free dimensions. An empty terminal core is handled entirely by this elimination, while a nonempty one is handled by the invertible determinant. F03-018 then gives admissibility with relative dimension equal to the number of sources minus the number of selected targets.

The correction verifier exhausts all 15,888 target selections in $D_4$ through $D_{12}$ and finds only the 25 predicted root-labelled cores. It independently constructs their Chevalley Jacobians; all 25 determinants are the stated monomials with coefficient $2$ or $-2$. For $D_8$ at height six it records $2x_{00000001}x_{00000010}x_{00000100}x_{00001000}x_{10000000}$. These finite checks certify the implementation and the concrete row; the uniform conclusion follows from the preceding root-pair and determinant argument.
