# Statement


Let $F/\mathbb Q_p$ be finite and let $\mathbf G$ be a connected reductive group with connected center, with $p>h_{\mathbf G}$. If $\mathbf G$ has type $F_4$, then every homomorphism $\operatorname{Gal}_F\to\mathbf G(\overline{\mathbb F}_p)$ has a crystalline lift. If $\mathbf G$ is an arbitrary reductive group and $[F:\mathbb Q_p]>\dim(\mathbf G)/2$, then every homomorphism $\operatorname{Gal}_F\to\mathbf G(\overline{\mathbb F}_p)$ has a crystalline lift.
