# Statement


Let $\Phi$ be a reduced root system with positive roots $\Phi^+$, fix a Chevalley basis with $[e_\beta,e_\delta]=N_{\beta,\delta}e_{\beta+\delta}$, and let $\fB$ be a directed bipartite graph whose source vertices $\fB^{\src}$ and target vertices $\fB^{\tar}$ are positive roots. Put
\[
\Delta_{\fB}=\{\alpha-\beta:\alpha\in\fB^{\tar},\ \beta\in\fB^{\src}\}\cap\Phi^+,\qquad \G_m^{\Delta_{\fB}}=\Spec\bFp[x_\delta,x_\delta^{-1}:\delta\in\Delta_{\fB}].
\]
The discriminant variety $\fD_{\fB}$ is the closed subvariety of
\[
\G_m^{\Delta_{\fB}}\times\Spec\bFp[y_\beta:\beta\in\fB^{\src}]
\]
defined, for every $\alpha\in\fB^{\tar}$, by
\[
\sum_{\beta\to\alpha}N_{\beta,\alpha-\beta}x_{\alpha-\beta}y_\beta=0.
\]
The graph $\fB$ is admissible if the projection $\fD_{\fB}\to\G_m^{\Delta_{\fB}}$ is smooth of relative dimension $\#\fB^{\src}-\#\fB^{\tar}$. The graph need not be an induced subgraph; only its vertices must be interpretable as positive roots.

### Faithful nearby example

```tex
Consider the cyclic graph $\vec C_6$:
\raisebox{-7ex}{\scalebox{.6}{\GraphCSix}}.
Write $\delta_1=\alpha_3-\beta_2$,
$\delta_2=\alpha_3-\beta_1$, and
$\delta_3=\alpha_2-\beta_1$.
If $\alpha_*$ are of height $h+1$ and $\beta_*$
are of height $h$,
then $\Delta_{\vec C_6} = \{\delta_1, \delta_2, \delta_3\}
\subset \Delta$.
Then the discriminant variety
is given by the equations
\begin{align*}
\begin{cases}
N_{\beta_2\delta_1}x_{\delta_1}y_{\beta_2} +
N_{\beta_1\delta_2}x_{\delta_2}y_{\beta_1}=&0 \\nN_{\beta_3\delta_2}x_{\delta_2}y_{\beta_3} +
N_{\beta_2\delta_3}x_{\delta_3}y_{\beta_2}=&0 \\nN_{\beta_1\delta_3}x_{\delta_3}y_{\beta_1} +
N_{\beta_3\delta_1}x_{\delta_1}y_{\beta_3}=&0,
\end{cases}
\end{align*}
whose
(relative) Jacobian matrix
is
$
\begin{pmatrix}
N_{\beta_1\delta_2}x_{\delta_2} &
N_{\beta_2\delta_1}x_{\delta_1} &
0 \\[6pt]
0 &
N_{\beta_2\delta_3}x_{\delta_3} &
N_{\beta_3\delta_2}x_{\delta_2} \\[6pt]
N_{\beta_1\delta_3}x_{\delta_3} &
0 &
N_{\beta_3\delta_1}x_{\delta_1}
\end{pmatrix}
$.
So,
$\vec C_6$ is admissible
if and only if
$
N_{\beta_2\delta_1}N_{\beta_3\delta_2}N_{\beta_1\delta_3}
+
N_{\beta_1\delta_2}N_{\beta_2\delta_3}N_{\beta_3\delta_1}
\neq 0.
$
Indeed, this value is \MINOREDITED{always} equal to one of
$\{2, -2, 3\}$
across all root systems,
and is non-zero if $p>3$.
```
