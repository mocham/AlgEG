# Statement


Let $T$ be a torus over a finite extension $K/\mathbb Q_p$, let $\mathcal T$ be its standard integral model, and let $f:T(K)\to\overline{\mathbb Q}_p^\times$ be a continuous character, called crystalline when its corresponding parameter $G_K\to{}^LT(\overline{\mathbb Q}_p)$ is crystalline. Then $f$ is crystalline if and only if $f|_{\mathcal T(\mathcal O_K)}$ is the restriction of an algebraic character $\operatorname{ev}(\chi_\bullet)$ arising from a cocharacter $\chi_\bullet\in X^*(\operatorname{Res}_{K/\mathbb Q_p}T)$.

# Proof or Examples


## Expanded self-contained proof

### Faithful full source excerpt

```text
Proposition 7. f : T(K) -> Qpbar^x is crystalline if and only if T(O_K) -> Qpbar^x is an algebraic character in the sense that there exists chi in X^*(T) such that f|_{T(O_K)} is the restriction of an algebraic character to T(O_K).

Proof. Since T(O_K) contains T(K)_0 = colim_{E/K unramified} T(E), crystallinity is completely determined by the restriction of f to T(O_K); algebraic characters ev(chi_bullet) are clearly crystalline of Hodge type chi_bullet. Conversely, the theory of weakly admissible filtered phi-module together with Dieudonne-Manin classification imply the Hodge type chi_bullet completely determines crystalline characters T(O_K) -> Qpbar^x, so ev(X^*(Res_{K/Qp} T)) exhausts all crystalline characters.
```

### Reviewer completion

An algebraic character ev(chi_bullet) is crystalline with Hodge type chi_bullet. If f is crystalline, let chi_bullet be its Hodge type and put g=f/ev(chi_bullet). The character g is crystalline of Hodge type zero, so D06-003 makes g trivial on the integral points; hence f and ev(chi_bullet) have the same restriction there. Conversely, if the restriction of f agrees with ev(chi_bullet), then g=f/ev(chi_bullet) is trivial on the integral points. By D06-003, g is an unramified crystalline character of Hodge type zero. The product f=g ev(chi_bullet) is therefore crystalline. This also makes precise why unrestricted values on the quotient T(K)/T_int(O_K) do not affect the criterion.
