# Statement


Let $p=5$, $K=\mathbb Q_5$, $G=H=\mathbb G_m$, and let $i=[2]:G\to H$. Give both split L-groups trivial Hodge type and trivial inertial type, and let $x$ be the trivial L-parameter. The fixed-type stacks exist, but at $x$ the induced map $\mathcal X_{K,{}^LH}^{1,0}\to\mathcal X_{K,{}^LG}^{1,0}$ sends the stabilizer $\mathbb G_m$ by $z\mapsto z^2$. Its kernel is the nontrivial group scheme $\mu_2$. Hence the stack morphism is not representable by algebraic spaces and therefore is not relatively representable by a finite morphism. This contradicts the assertion that every central isogeny with finite kernel induces a relatively representable finite morphism between the corresponding fixed-type stacks.

# Proof or Examples


## Expanded self-contained proof

The map $[2]:\mathbb G_m\to\mathbb G_m$ is a central isogeny with finite kernel $\mu_2$, and its dual map is again $[2]$. Split tori are tame, so the cited existence result supplies both fixed-type stacks. The trivial parameter is crystalline of Hodge type zero and has trivial inertia, so it is an object of the source fixed-type stack. Parameters are taken up to dual-group conjugacy. Since $\mathbb G_m$ is abelian, the automorphism group of the trivial source parameter and that of its image are both $\mathbb G_m$. Functoriality sends an automorphism $z$ to $z^2$, so the stabilizer map has kernel $\mu_2\ne1$. If a stack morphism is representable by algebraic spaces, base change by any target object is an algebraic space and has no nontrivial object automorphisms; equivalently every source-to-target stabilizer map is a monomorphism. The displayed stabilizer map is not, so representability fails. This is a stack-level obstruction: passing to coarse parameter spaces would discard precisely the stabilizer that causes the contradiction.
