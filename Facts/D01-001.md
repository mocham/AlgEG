# Statement


Let $k$ be a field, let $R=k[x_1,\dots,x_n]$, let $I\subseteq R$ be an ideal, and let $h\in R$. Define $I:h^\infty=\{f\in R: h^Nf\in I\text{ for some }N\geq 0\}$. Then the following are equivalent: (i) $I:h^\infty$ is a proper ideal of $R$; (ii) the extended ideal $IR_h$ is proper in the localization $R_h$; and (iii) there are a field extension $L/k$ and a tuple $a\in L^n$ such that $f(a)=0$ for every $f\in I$ and $h(a)\neq 0$. Consequently, when $I$ is generated by polynomial equations and $h$ is their square Jacobian determinant, properness after saturation by $h$ is equivalent to existence, over some field extension, of a solution where that Jacobian is invertible.

# Proof or Examples


## Expanded self-contained proof

The contraction of $IR_h$ along $R\to R_h$ is $I:h^\infty$: an element $f$ maps into $IR_h$ exactly when $h^Nf\in I$ for some $N\geq0$. Moreover, $IR_h=R_h$ exactly when $h^N\in I$ for some $N$, which is exactly when $1\in I:h^\infty$. This proves (i) if and only if (ii). If $IR_h$ is proper, choose a maximal ideal $\mathfrak m$ containing it and put $L=R_h/\mathfrak m$. The images $a_i$ of the variables satisfy every element of $I$, while the image of $h$ is nonzero because $h$ is a unit in $R_h$; hence (iii). Conversely, a tuple as in (iii) defines an evaluation map $R_h\to L$, since $h(a)$ is invertible, and this map kills $IR_h$. Thus $IR_h$ is proper. For a square Jacobian matrix over the field $L$, invertibility is equivalent to nonvanishing of its determinant, giving the final assertion.
