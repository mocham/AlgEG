# Statement


Let $F/\mathbb Q_p$ be finite, let $A$ be an $\overline{\mathbb F}_p$-algebra, and let $\mathbf G$ be a split pinned connected reductive group with connected center, Borel subgroup $\mathbf B=U\rtimes\mathbf T$, positive roots $\Phi^+$, and $p>h_{\mathbf G}$. Fix $f^{\mathrm{ss}},g^{\mathrm{ss}}\in\mathbf T(\mathbf E_{F,A})$, put $\gamma_g(u)=g^{\mathrm{ss}}\gamma(u)g^{\mathrm{ss},-1}$ and $\varphi_f(u)=f^{\mathrm{ss}}\varphi(u)f^{\mathrm{ss},-1}$, and fix Chevalley root vectors $e_\beta$. For each $\beta\in\Phi^+$ let $c_\beta=(c_{f,\beta},c_{g,\beta})\in C^1_{\mathrm{Herr}}(U_{\beta^\vee}(\mathbf E_{F,A}))$. If $\beta_1+\beta_2\in\Phi^+$, define
\[
c_{\beta_1}\smile c_{\beta_2}=\left(\frac{c_{f,\beta_1}}{e_{\beta_1}},\frac{c_{g,\beta_1}}{e_{\beta_1}}\right)\smile\left(\frac{c_{f,\beta_2}}{e_{\beta_2}},\frac{c_{g,\beta_2}}{e_{\beta_2}}\right)e_{\beta_1+\beta_2},
\]
where $(x_f,x_g)\smile(y_f,y_g)=x_f\varphi_f(y_g)-x_g\gamma_g(y_f)$. More generally, let $\beta_1,\ldots,\beta_n\in\Phi^+$ satisfy $\beta_i+\cdots+\beta_n\in\Phi^+$ for every $1\leq i<n$. Define
\begin{align*}
[c_{\beta_1},\ldots,c_{\beta_n}]={}&[c_{g,\beta_1},[c_{g,\beta_2},\ldots,[c_{g,\beta_{n-1}},\gamma_g(c_{f,\beta_n})]\ldots]]\\
&-[c_{f,\beta_1},[c_{f,\beta_2},\ldots,[c_{f,\beta_{n-1}},\varphi_f(c_{g,\beta_n})]\ldots]],
\end{align*}
which is a well-defined degree-two cochain in the successive root bracket. For $n=2$, if $[e_{\beta_1},e_{\beta_2}]=N_{\beta_1,\beta_2}e_{\beta_1+\beta_2}$, then
\[
c_{\beta_1}\smile c_{\beta_2}=-N_{\beta_1,\beta_2}^{-1}[c_{\beta_1},c_{\beta_2}].
\]

# Proof or Examples


## Expanded self-contained proof

The successive-root hypothesis ensures that every inner Lie bracket is a scalar multiple of the Chevalley vector for the corresponding tail sum, so all displayed terms are defined. Chevalley structure constants that occur in a root string have absolute value at most $3$; the standing hypothesis $p>h_{\mathbf G}$ makes them units whenever the corresponding root sum exists.

For $n=2$, the Chevalley relation gives
\[
[c_{g,\beta_1},\gamma_g(c_{f,\beta_2})]-[c_{f,\beta_1},\varphi_f(c_{g,\beta_2})]
=-N_{\beta_1,\beta_2}\bigl(c_{\beta_1}\smile c_{\beta_2}\bigr).
\]
Division by the unit $N_{\beta_1,\beta_2}$ proves the final identity. For longer admissible tuples the nested expression is a definition, and the same tail-root condition identifies its target degree-two root coordinate.
