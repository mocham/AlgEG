# Statement


Let $\Phi^+$ be the positive roots of a split reductive group with Borel $\bB=U\rtimes\bT$. A fine configuration is a tuple $(K,\Psi_0,\Psi_2)$ in which $K\subset U$ is a $\bT$-stable normal subgroup and $\Psi_0,\Psi_2\subset\Phi^+$ satisfy: (i) if $\alpha,\beta\in\Psi_2$ and $\alpha-\beta\in\Phi^+$, then $\alpha-\beta\in\Psi_0$; and (ii) if $\alpha\in\Psi_2$, $\beta\in\Psi_0$, and $\alpha+\beta\in\Phi^+$, then $\alpha+\beta\in\Psi_2$. Define
\[
\mathcal D(\Psi_0,\Psi_2)=\left\{\sum_i n_i\;\middle|\;n_i\in\mathbb Z_{\ge0},\ \sum_i n_i>0,\ \alpha=\sum_i n_i\alpha_i\text{ for some }\alpha\in\Psi_0\text{ and }\alpha_i\in\Psi_2\right\}.
\]
The minimal degree is the extended positive integer
\[
\deg(\Psi_0,\Psi_2)=\begin{cases}\min\mathcal D(\Psi_0,\Psi_2),&\mathcal D(\Psi_0,\Psi_2)\ne\varnothing,\\+\infty,&\mathcal D(\Psi_0,\Psi_2)=\varnothing.\end{cases}
\]

# Proof or Examples


## Expanded self-contained proof

This is a definition, so no proof is required. It is well-defined: every element of D(Psi_0,Psi_2) is a positive integer, hence any nonempty such set has a minimum by well-ordering; the empty case is assigned +infinity.

As a basic check, deg(Psi_0,Psi_2)=1 if and only if Psi_0 intersects Psi_2. Indeed, a common root gives a one-term expression with coefficient 1. Conversely, an expression whose coefficient sum is 1 has exactly one nonzero coefficient, equal to 1, so the represented root lies in both subsets. If Psi_0 or Psi_2 is empty, then D is empty and the degree is +infinity.
