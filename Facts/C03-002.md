# Statement


Let $\Phi$ be the root system $D_8$ with Bourbaki simple-root coordinates, and take the adjacent-height graph $\mathcal B(\Phi^+,\Delta,6)$. Its complete source-to-target adjacency is
```text
00011211 -> 00012211, 00111211
00111111 -> 00111211, 01111111
01111101 -> 01111111, 11111101
01111110 -> 01111111, 11111110
11111100 -> 11111101, 11111110
```
Every source has two outgoing edges, so source-leaf contraction performs no step; there are five sources, five targets, and ten edges. This terminal graph is $K_{8,3}\cong\vec C_6\cup_{K_1}\vec P_5$, the stable $D_8$ height-six row of the complete Type D table.

# Proof or Examples


## Expanded self-contained proof

SageMath 10.9 reproduces the full two layers directly from the root lattice:
```python
L = RootSystem(["D", 8]).root_lattice()
roots = [tuple(int(c) for c in r.to_vector()) for r in L.positive_roots()]
simple = {tuple(int(c) for c in r.to_vector()) for r in L.simple_roots().values()}
S = sorted(r for r in roots if sum(r) == 6)
T = sorted(r for r in roots if sum(r) == 7)
adj = {s: [t for t in T if tuple(t[i]-s[i] for i in range(8)) in simple] for s in S}
print(len(S), len(T), sum(len(v) for v in adj.values()))
for s in S:
    print(s, adj[s])
```
The output is the five displayed rows and the count `5 5 10`. The source degrees are $(2,2,2,2,2)$ and the target degrees are $(1,2,2,2,3)$, so no source satisfies the contraction criterion from F03-015. The graph is connected.

In the notation of COR12-001, $n=8$, $h=2m=6$, and $a=n-2m=2$. The cycle has sources $A_0=P_{2,8}$, $B=M_{2,8}$, $C=M_{1,7}$ and targets $Q_0=P_{1,8}$, $Q_1=P_{2,7}$, $R=M_{1,8}$. The remaining sources $A_1=P_{3,7}$ and $A_2=P_{4,6}$ and targets $Q_2=P_{3,6}$ and $Q_3=P_{4,5}$ form the alternating tail $Q_1-A_1-Q_2-A_2-Q_3$. Hence the displayed graph is exactly $\vec C_6\cup_{K_1}\vec P_5$.
