# Statement


Let \(\mathbf G\) be a split connected reductive group with based root system \((\Phi,\Phi^+,\Delta)\), and let \(\mathbf M\subsetneq\mathbf G\) be the standard Levi defined by \(\Delta_{\mathbf M}\subset\Delta\). Write \(\Phi_{\mathbf M}\) for its root system and \(\Phi^{\mathbf M+}=\Phi^+\setminus\Phi_{\mathbf M}\). For \(\lambda=\sum_{\delta\in\Delta}n_\delta\delta\), put
\[
\operatorname{Ht}^{\mathbf M}(\lambda)=\sum_{\delta\notin\Delta_{\mathbf M}}n_\delta.
\]
Direct the graph on \(\Phi^{\mathbf M+}\) by \(\beta\to\alpha\) when \(\alpha-\beta\in\Phi^{\mathbf M+}\) and \(\operatorname{Ht}^{\mathbf M}(\alpha-\beta)=1\). If \(w\in N_{\mathbf M}(\mathbf T)\) has elliptic Weyl image, define the \(w\)-root poset to be the quotient directed graph
\[
\boldsymbol\Phi^{\mathbf M+}=\Phi^{\mathbf M+}/\langle w\rangle,
\]
with an arrow when some representatives have an arrow. Its relative simple roots are the orbits of relative height one. For an integer \(h\), let \(\mathcal B(\boldsymbol\Phi^{\mathbf M+},h)\) be the induced directed bipartite subgraph on orbits of relative heights \(h\) and \(h+1\), directed from height \(h\) to height \(h+1\).

For \(S\subset\boldsymbol\Phi^{\mathbf M+}\), put
\[
A_S=\bigcup_{\boldsymbol\alpha\in S}\boldsymbol\alpha,
\qquad
D(S)=\{\gamma-\gamma':\gamma,\gamma'\in A_S\}.
\]
Define \(S\) to be non-obstructing when
\[
D(S)\cap\Phi_{\mathbf M}\ne\varnothing,
\]
equivalently when two roots in \(A_S\) differ by a nonzero Levi root. A relative root is non-obstructing by applying this definition to its singleton. An induced directed bipartite subgraph is non-obstructing when its target-vertex set is non-obstructing.

# Proof or Examples


## Expanded self-contained proof

Relative height is constant on every \(w\)-orbit because \(w\) lies in the Weyl group of the Levi, so the quotient graph and its height layers are well defined. The non-obstructing predicate is the existential predicate used in the source proofs: a Levi root occurs as a difference. Since a root system does not contain zero, nonempty intersection with \(\Phi_{\mathbf M}\) is equivalent to existence of a nonzero Levi-root difference.

## Post-proof remarks

Verified as the corrected definition replacing F04-006. The manuscript prints intersection \(\ne\{0\}\), but \(0\notin\Phi_{\mathbf M}\), so that literal predicate would also classify an empty intersection as non-obstructing. The surrounding proof and later applications uniquely determine the correction to nonempty intersection. This unit verifies only the definitions and their well-definedness, not a theorem that particular cycles are non-obstructing or admissible.
