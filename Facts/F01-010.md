# Statement


For $\PGL_n$, the term *gauge cochains* denotes the recursively defined minimal set of degree-$1$ cochains in the relevant Herr complexes for which the universal family on the partially reduced Borel-valued Emerton--Gee stack $\cX_{\bB_{\PGL_n}}$ can be expressed as a linear combination of those cochains with coefficients in a multivariable Laurent polynomial ring $\bFp[t_1^{\pm1},\ldots]$.
