# Statement


Let $F/\mathbb Q_p$ be finite, let $\mathbf G$ be a split connected reductive group over $\overline{\mathbb F}_p$ with connected center, assume $p>h_{\mathbf G}$, and fix a Borel subgroup $\mathbf B$. Then there is a finite set of regular Borel Hodge types $\{\underline\lambda_s:s\in S\}$ such that:

1. the special fiber of $\bigcup_{s\in S}\mathcal X_{\mathbf B}^{\underline\lambda_s,\tau_{\mathrm{triv}}}$ maps surjectively onto the Borel-valued mod-$p$ Weil--Deligne stack $\mathcal W_{\mathbf B}$;
2. for every irreducible component $C\subset\mathcal W_{\mathbf B}$, that special fiber contains the closure $\overline{\dot{\mathcal X}_{\mathbf B}(C)}$ of the maximally nonsplit locus over $C$.

# Proof or Examples


## Expanded self-contained proof

By COR10-002, $\mathcal W_{\mathbf B}$ is a finite-type algebraic stack, hence noetherian with only finitely many irreducible components. Apply COR8-003 to each irreducible component $C$. It supplies a regular Borel Hodge type $\underline\lambda_C$ with trivial inertial type whose crystalline special fiber contains $\overline{\dot{\mathcal X}_{\mathbf B}(C)}$. Taking one such type for each component gives a finite set $S$ and proves part 2. The maximally nonsplit locus over $C$ is scheme-theoretically dominant over $C$; the proper-image input used in COR8-003 makes the corresponding crystalline image closed. Its image therefore contains the closure of that dense locus, namely all of $C$. The finite union maps onto every component of $\mathcal W_{\mathbf B}$, proving part 1. No uniqueness assertion for components over $C$ is needed.

## Post-proof remarks

Verified after the height-one repair of COR8-003. COR10-002 makes the Borel Weil--Deligne stack finite type with finitely many irreducible components. For each component, COR8-003 uses PGL2 rank-one coverage on the height-one truncation and then the closed \(N=0\) base change of COR17-009; it does not repeat Lin25's component argument. Selecting one type per component is finite, proves component containment, and the scheme-theoretically dominant maximally nonsplit locus makes the resulting union map onto every Weil--Deligne component. No uniqueness of a Borel or parabolic reduction is used.
