# Statement


Let $F/\mathbb Q_p$ be finite, let $k=\overline{\mathbb F}_p$, let $\mathbf G$ be a split connected reductive group over $k$, and fix a Borel $\mathbf B=U\rtimes\mathbf T$ with positive roots $\Phi^+$. Let $K\subset U$ be a $\mathbf T$-stable normal subgroup with root set $\Phi_K$. Let $\mathcal S=\mathcal X_{K\rtimes\mathbf T}[K]\langle\Psi\rangle$ be a finite-type locally closed substack of the mod-$p$ stack of continuous $G_F$-representations, classifying $K\rtimes\mathbf T$-valued objects such that, for every object with torus semisimplification $\rho^{\mathrm{ss}}$, the set of positive roots whose character is trivial on $\rho^{\mathrm{ss}}$ is the fixed set $\Psi_0$. Let $H_0\subset U$ be the subgroup generated by $U_{\beta^\vee}$ for $\beta\in\Psi_0$, and put $\overline H_0=H_0/(H_0\cap K)$. Then positive-root conjugation induces an action of $\overline H_0$ on $\mathcal S$, and the natural morphism $\mathcal S\to\mathcal X_{\mathbf G}^{\mathrm{EG}}$ factors through $[\mathcal S/\overline H_0]$. Moreover, $\dim\overline H_0=\#(\Psi_0\setminus\Phi_K)$, so the scheme-theoretic image has dimension at most $\dim\mathcal S-\#(\Psi_0\setminus\Phi_K)$. In particular, if $\Psi_0\subset\Phi^+\setminus\Phi_K$, the bound is $\dim\mathcal S-\#\Psi_0$.

# Proof or Examples


## Expanded self-contained proof

Because $\Psi_0$ is the set of trivial root characters, it is closed under addition whenever a sum is a root. Hence the root groups indexed by $\Psi_0$ generate a smooth unipotent subgroup $H_0$ having exactly those roots. Write an object as $\rho(\sigma)=c_\sigma t_\sigma$ with $c_\sigma\in K$ and $t_\sigma\in\mathbf T$. Normality of $K$ in $U$ gives $h c_\sigma h^{-1}\in K$ for $h\in H_0$. Every root character occurring in $H_0$ is trivial on $t_\sigma$, so $h$ commutes with $t_\sigma$. Thus $h\rho h^{-1}$ is again $K\rtimes\mathbf T$-valued. Conjugation preserves the fixed torus-character conditions and the minimal-$K$ locally closed locus, so it acts on $\mathcal S$.

The subgroup $H_0\cap K$ acts by the change-of-framing already present in the $K\rtimes\mathbf T$ representation stack. Consequently the induced effective action is by $\overline H_0=H_0/(H_0\cap K)$. Conjugate representations define the same object of the $\mathbf G$-valued stack, which supplies the descent datum and the factorization through $[\mathcal S/\overline H_0]$. Root-subgroup factorization gives $\dim H_0=\#\Psi_0$ and $\dim(H_0\cap K)=\#(\Psi_0\cap\Phi_K)$; therefore $\dim\overline H_0=\#(\Psi_0\setminus\Phi_K)$. Finally, a finite-type morphism has scheme-theoretic image of dimension no larger than its source, while $\dim[\mathcal S/\overline H_0]=\dim\mathcal S-\dim\overline H_0$. This proves both bounds.

The rank-one calculation in C02-001 illustrates both repairs. There $H_0=K=U_\alpha$, so the effective positive-root quotient is trivial, whereas conjugation by $U_{-\alpha}$ does not preserve the Borel-valued locus.
