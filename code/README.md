# Algorithmic Emerton-Gee stacks

This is the repo that computes the irreducible components of the reduced Emerton-Gee stacks.

The original v1 is entirely written by the author. The later v2-v4 iterations are generated by ChatGPT 5.6 sol.

# Computational Certification

The reviewed implementation is [`code/v4/`](https://github.com/mocham/AlgEG/tree/main/code/v4).
This file is the canonical record of code rules, algorithms, artifacts,
checksums, and rough runtimes. The paper's appendices describe only the
mathematical pseudocode and the numerics used in the proofs.

## Rules

1. `code/v4/` is self-contained and does not import archived implementations.
2. Root systems, order ideals, Chevalley constants, elliptic Weyl orbits, and
   twisted-cycle configurations are generated internally.
3. The reviewed F4 pair inventory is an allowed input. It is validated on every
   exhaustive run and regenerated from first principles only when absent.
4. Generated certificate JSON files are outputs. No classification certificate
   is used as a mathematical input.
5. Every machine-assisted theorem records its scope, counts, exact rank
   witnesses, SageMath version, and SHA-256 digest.
6. Adding a root to `Psi2` strictly increases minimal degree. A BFS branch may
   therefore retain its boundary node and stop without generating descendants.
7. The exhaustive method computes the field-degree bound before considering
   pair data. It never scans all `2^|Phi+|` subsets.

## F4 Pair Inventory

The canonical inventory is
[`psi-pairs-f4-v12.json`](https://github.com/mocham/AlgEG/blob/main/code/v4/DATA/psi-pairs-f4-v12.json).
It contains the 4,862 reviewed `(Psi0, Psi2)` pairs.

An ordinary certification run performs the following short check.

1. Load the 4,862 pairs.
2. Recompute affine consistency, the forced integral difference lattice,
   `Psi0`, and both closure conditions for every pair.
3. Regard every reviewed pair as a terminal BFS state, so no descendants are
   generated.
4. Generate all linearly independent subsets at the active degree bound.
5. Check that every relevant independent subset occurs among the reviewed
   pairs. There are 3,002 relevant subsets, and all 3,002 occur.
6. Classify the reviewed pairs against the 104 nonempty `K` complements.

If the inventory file is absent, `load_or_generate_f4_pairs()` invokes the
first-principles independent-seed BFS, writes the canonical inventory and its
checksum, and then runs the same validation. The fallback visits 50,347
affine-compatible subsets, begins with 9,780 independent seeds, and returns the
same 4,862 pairs with pair-list digest
`62327f69dc82bb81db8aaecf34369ca74653b2e708a92fd87004eaf617caa2fd`.

The formal product has `105 * 4862 = 510510` entries. The 4,862 empty-complement
entries do not define nontrivial `K`-strata. Of the remaining 505,648 entries,
294,388 are removed by the target-count bound and 211,260 receive exact
polynomial Jacobian-rank checks. Exactly four have epsilon zero.

## Reproduction

Run with SageMath 10.9 from `code/v4/`:

```sh
python -m unittest discover -s tests -v
python cli.py quick
python cli.py f4-exhaustive
python cli.py twisted-cycles
```

`python cli.py all` runs all certificates. To force a first-principles pair
reconstruction, temporarily remove `DATA/psi-pairs-f4-v12.json` and its
checksum, run `python cli.py f4-exhaustive`, and restore only if comparing
outputs. The fallback run records that first principles were used; run the
command once more to reproduce the ordinary reviewed-data certificate. Do not
edit the reviewed inventory by hand.

All documents use schema `grob-computation-v12`, sorted indented JSON, and one
terminal newline. Check the manifests from `code/v4/DATA/` with:

```sh
sha256sum -c -- *.sha256
```

## Rough Runtimes

These wall times were observed in the August 2026 workspace and are only
planning estimates.

| Task | Rough time | Remarks |
|---|---:|---|
| Pair inventory certification | 2m21s | Loads 4,862 terminal pairs; no first-principles BFS |
| Missing-data fallback | 4m45s | Reconstructs the inventory, then certifies and classifies |
| Pair-generation phase alone | 2m05s--2m06s | 50,347 visited nodes |
| Unit tests | 2m43s | 12 tests; exceptional roots and pair-inventory checks dominate |
| Elliptic Weyl plus twisted cycles | 1m44s | Run separately from `quick` |

The monotone-degree cutoff has shown about a 30% gain when branches reach the
active boundary. The degree-one F4 run has the same 50,347 first-principles
node count, so compare both wall time and branch counters for other bounds.

## Source Map

| Module | Responsibility |
|---|---|
| `roots.py` | Cartan-generated roots, root order, structure constants |
| `graphs.py` | Height layers, induced graphs, contractions |
| `algebra.py` | Exact monomial and polynomial rank witnesses |
| `bounded_strata.py` | Degree bound, pair inventory, fallback BFS, F4 classification |
| `borel.py`, `cone.py` | Displayed table and grouped cone checks |
| `cycles.py` | Absolute exceptional cycle certificates |
| `elliptic_weyl.py` | Elliptic Weyl orbits and non-Borel strata generation |
| `twisted_cycles.py` | Relative and associated absolute cycle checks |
| `rotation.py` | Rational rotation points and integral spreading |
| `cli.py` | Canonical JSON and SHA-256 output |
